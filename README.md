Entry for the make.fun bounty "The Funniest Out-of-Office": one
out-of-office auto-reply, a single line, at most 140 characters. A judge
model playing a comedy editor compares entries pairwise.

Run `python3 main.py` — it writes the line to `/output/entry.txt`.
